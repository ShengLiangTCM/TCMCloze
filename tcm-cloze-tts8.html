1. TXT文件

1.1 篇章分隔

每篇独立内容之间，用 ===== （5个半角等号）单独占一行进行分隔。

1.2 单篇结构

每篇的第一行为标题（可含编号，如 1. 手太阴肺经 ）。
后续所有行均为正文内容。

1.3 挖空语法

需要做成填空的内容，用 【答案文本】 包裹，例如：
太阳之为病，脉【浮】，头项【强痛】而恶寒。

1.4 发音修正（可选）

生僻字或多音字需要指定朗读发音时，用 {原字|读音字} 标记，例如：
{恶|误}寒 → 朗读时会按"误寒"发音。


2. JSON文件

2.1 JSON 需为数组

每项含 name 和 text 字段。
name 字段即标题。
text 字段即正文，使用\n换行。

2.2 其他格式

挖空语法 与 发音修正 与 TXT 文件格式相同。


示例（TXT）：

=====
手太阴肺经
肺【手太阴】之脉，起于【中焦】，下络【大肠】，{还|环}循【胃口】……
=====
手阳明大肠经
大肠【手阳明】之脉，起于【大指次指】之端，循【指上廉】，出【合谷两骨之间】……

示例（JSON）：

[
  {"name":"手太阴肺经","text":"肺【手太阴】之脉，起于【中焦】……"},
  {"name":"足太阴脾经","text":"脾【足太阴】之脉……注【心中】。\n脾之大络，名曰【大包】……"},
]

注：保存为 UTF-8 编码的 .txt 或 .json 文件即可导入。
